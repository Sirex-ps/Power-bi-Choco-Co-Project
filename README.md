Power BI Dashboard Development for a Chocolate Company

designed and development of a fully interactive Power BI dashboard tailored for a chocolate manufacturing and distribution company. The dashboard consolidated and visualized key business metrics including Total Sales, Cost, Profit, Shipments, and Number of Boxes Sold, offering both high-level summaries and granular, drill-down insights.

Key features included:
	•	Dynamic Filtering Capabilities: Implemented slicers and filters to allow users to analyze data by geographical regions (e.g., countries, states) and product categories (e.g., chocolate type, packaging format). This empowered business users to quickly identify trends, opportunities, and underperforming areas.
	•	Data Model Optimization: Cleaned and transformed raw data using Power Query and DAX to ensure accurate measures and relationships across multiple data sources. Created calculated columns and KPIs to support profitability and performance tracking.
	•	Interactive Visuals: Incorporated bar charts, line graphs, treemaps, and map visuals to present trends and comparisons in an intuitive and visually compelling way.
	•	Actionable Insights: Provided insights into cost-to-profit ratios, shipment performance by region, and product-level contribution margins—enabling leadership to make more informed decisions on pricing, logistics, and inventory planning.
	•	Improved Decision-Making: The dashboard became a central tool for weekly sales reviews and strategic planning, significantly improving the speed and accuracy of data-driven decisions across departments.
